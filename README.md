# GMI × Acclime Referral Partnership deck

A 12-slide deck for General Magick Industries, offering Acclime a referral partnership built around AI workflow automation.

**Deck:** https://claude.ai/artifact/Qa719oAxraohZoRE9rH7vy

## How to use this with Claude

1. Clone this repo.
2. Open a terminal in the folder and run `claude`. You must be logged in with a claude.ai account.
3. Type `hello`. Claude explains the deck and what was done.
4. Ask for changes in plain words, for example: "Change the referral fee to 10%."

To change the same link, the deck owner must first share the deck with you with **edit** access. Without it, Claude can make your own copy instead.

## What's inside

- `CLAUDE.md`: the full briefing and rules Claude reads automatically
- `project/`: the slide files (`deck.json`, `deck.css`, `slides/`)
- `images.md`: which image file is used where
- `brand/`: logo, photos and product images from generalmagickindustries.com
- `theme.md`: colors, fonts and the overall look
